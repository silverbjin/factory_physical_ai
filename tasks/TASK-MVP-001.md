# TASK-MVP-001 — Factory Agent Vertical Slice

> Status: READY FOR EXECUTION
> Phase: Day-10 MVP
> Architecture prerequisite: TASK-P0-002 = GO
> Physical robot authorized: NO
> VLA runtime/fine-tuning required: NO
> Scope invariant: 1 Mission + 1 Failure + 1 Recovery + Evidence


## 1. Goal

Create the smallest executable vertical slice that converts the single canonical natural-language factory mission into a validated structured mission request.

Canonical mission:

> `Line B에 Brake ECU Type-B 1개를 공급해줘.`

This task proves the **Agent semantic boundary only**. It must not implement robot execution, persistence, recovery, ROS 2, VLA, or external services.

## 2. Architecture boundary

Allowed flow:

```text
Natural Language
    ↓
Factory Agent / Provider Interface
    ↓
Structured Mission
    ↓
Schema Validation
```

Forbidden:

- raw ROS/Nav2 commands;
- poses or trajectories generated by the LLM;
- WMS/Fleet/PHM service implementation;
- physical robot calls;
- VLA calls;
- multi-agent architecture;
- LangGraph dependency;
- networked microservices.

Use a deterministic fake provider as the required test provider. A real hosted provider is not required.

## 3. Required structured output

At minimum:

```text
schema_version
mission_id
mission_type
part_id
quantity
destination
requested_by
created_at
```

Use typed models (for example dataclass/Pydantic) consistent with the frozen contract.

## 4. Required implementation

Create only the minimum application skeleton needed for:

- provider abstraction;
- deterministic fake provider;
- mission parser/agent boundary;
- structured mission model;
- schema validation;
- CLI or test entry point for the canonical mission.

Recommended initial package boundaries:

```text
src/
  factory_agent/
  contracts/
tests/
```

Do not add packages that are not needed for this task.

## 5. Tests

Required:

1. canonical Korean mission parses successfully;
2. structured mission contains `Brake ECU Type-B`;
3. quantity is `1`;
4. destination is `Line B`;
5. invalid provider output is rejected by schema validation;
6. no execution-layer command is produced.

## 6. Evidence

Create:

`results/mvp/MVP-001.json`

Record only measured test results, changed files, and validation status.

## 7. Exit Criteria

- [ ] canonical mission produces a valid structured mission;
- [ ] fake provider is deterministic;
- [ ] malformed provider output fails closed;
- [ ] no robot/ROS/VLA implementation exists;
- [ ] tests pass;
- [ ] `git diff --check` passes;
- [ ] evidence file exists.

## 8. Commit

Use after Exit Criteria pass:
